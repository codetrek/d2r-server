# 原生传输观察文件格式

这是固定 Darwin ARM64 研究构建的私有观察格式，所有整数使用小端。它记录方法调用尝试和原始方法返回后的队列出队，不能据此宣称完整网络协议或全部流量。`format.h` 是权威字段定义，`abi.h` 是 ARM64 调用垫片与 C 观察器之间的内存契约。

文件通过 `D2R_TRANSPORT_TRACE` 指定的新路径创建，使用 `O_EXCL` 和权限 `0600`，固定映射 64 MiB。`D2R_PROBE_MODULES` 必须指向本次宿主实际装载的模块目录，其中 `main.patched.bin` 和 `sdk.patched.bin` 必须匹配固定画像。观察上限 1 MiB 是采样资源限制，不是游戏或网络消息长度上限。

`D2R_PROBE_STOP_PATH` 必填，必须是安装时不存在的绝对路径。控制方完成游戏与保存退出判据后，在该路径新建属于本次运行的普通文件，等待头部的关闭标志，再结束宿主。控制线程只轮询这个宿主文件及采样状态，不读取 Guest 内存，也不调用帧号函数。文件创建到控制线程观察之间仍可能接纳调用；实际窗口以准入关闭和完成屏障为界。

## 固定画像与构建边界

`profile.json` 固定原始模块的大小、SHA256、平台、原生源文件列表和集成符号。包装函数只在原始 `main.c` 这个编译单元使用 `run_module_inits=d2r_observed_run_module_inits` 重命名后参与链接；原来的 `loader.c` 保持原名。包装函数同步调用原始初始化一次，随后验证画像并安装观察器，最后才返回原来的 `nnMain` 启动流程。只有 `integration.c` 包含上游 `dm.h`，核心和合成测试不依赖游戏或上游头文件。

画像同时检查模块文件和当前对象、虚表、全部已知表项。服务端复制 14 个方法槽加两个负偏移头，客户端复制 26 个方法槽加两个负偏移头；仅替换四个观察槽，客户端次级对象的原虚表指针保持原值。这里没有代码页改写、源文件补丁、动态库注入或签名绕过。模块文件哈希匹配也不等于 Apple 签名验证。

服务端被原函数忽略的连接号、模式和关闭状态在读取跨度描述符之前判断；这些调用即使传入空描述符也继续原样转调。客户端模式 3 是未覆盖分支，会明确产生采样缺口。所有观察都只在安装线程复制字节，其他线程仅记录错误计数并转调原函数。初始化后的安装位置本身不能证明全部线程已静止，实际采样一旦出现线程违规就不能通过完整性判据。

## 记录

每条记录由 64 字节头、负载和补齐到 8 字节边界的零组成。记录序号从 1 连续递增。

| 偏移 | 类型 | 内容 |
|---:|---|---|
| 0 | u32 | 包含补齐的记录总长 |
| 4 | u16 | 类别：1 服务端发送尝试，2 客户端发送尝试，3 系统出队，4 游戏命令出队 |
| 6 | u16 | 记录标志，见下文 |
| 8 | u64 | 序号 |
| 16 | u64 | 宿主原子帧号快照 |
| 24 | u64 | 本次调用的系统线程编号 |
| 32 | u32 | 连接号，仅标志 128 时有效 |
| 36 | u32 | 调用前模式；出队记录为 0 |
| 40 | u32 | 实际复制的负载长度 |
| 44 | u32 | 保留，零 |
| 48 | u64 | 原负载长度；没有读取描述符的忽略调用和空结果为 0 |
| 56 | u64 | 保留，零 |

记录标志是位集合：1 有复制负载，2 原方法忽略该调用，4 空出队，8 无效跨度，16 超过观察上限，32 线程违规，64 采样缺口，128 有连接号。带缺口、错误、溢出或线程违规的文件不能作为完整采样通过依据。非安装线程只更新原子错误计数并原样转调，避免并发写入单写者记录区，因此记录数可以小于调用次数。

发送记录的负载只包含原来的 opaque payload。出队记录的负载包含 `[u32LE 连接号 | payload]`，不含内部队列的 u16 长度前缀；仍需保留类别作为独立元数据。空出队不读取未初始化的结果指针或填充。忽略的发送调用不读取跨度描述符。文件中不保存 Guest 指针、返回地址或寄存器原值。

显式结束使用 `OPEN → CLOSING → CLOSED` 屏障。每次获准采样的方法调用在执行原函数前取得在途令牌，直到原函数返回并完成所需的出队负载复制后才释放。控制线程先关闭新采样准入，再等待全部在途令牌释放，然后同步已提交记录并关闭文件描述符，最后发布关闭标志。

准入关闭后开始的方法调用属于采样区间之外：仍原样执行原函数一次，保留参数和返回值，不写记录、计数或错误标志。在关闭前获准的调用必须完成复制，其区间内错误仍会使采样失败。正式构建保留有界映射和原方法指针到进程结束，只有合成测试在确认测试线程结束后回收映射。

宿主的 SIGTERM、拍数上限等退出路径使用 `_exit`，不会运行 `atexit`。观察器不依赖退出回调完成采样；未请求并完成显式结束就退出的文件保持未关闭状态，不能通过完整性判据。

正常转调先后关系、返回寄存器和 `x8` 间接结果由原生垫片保留。复制后的负载归文件映射所有，没有后台读取 Guest 内存的线程。观察器不会构造或投递游戏消息。

## 验证

在 Darwin ARM64 上运行 `native/transport-probe/tests/run.sh`。所有构建产物和合成观察文件都位于仓库的 `.tmp/native-probe/`。测试验证整数与向量参数、返回寄存器、NZCV、`x8` 间接结果、原函数仅执行一次、负载自有副本、空结果保护页、忽略调用的描述符保护、长度和采样上限、线程违规、容量溢出、文件独占创建、合成哈希校验和完整虚表复制。并发测试让原函数阻塞，确认结束请求会等待原函数及出队复制；随后安装线程和其他线程的区间外调用不改变头部。子进程 `_exit` 测试确认未显式结束的文件保持未关闭。帧号测试函数只允许安装线程调用。

合成模块摘要测试使用公开的 `abc` 黄金样例；ABI 原函数也是本仓库的合成汇编函数。合成观察文件没有画像匹配和已安装标志，不能作为真实游戏画像的正向验证。实际模块画像、启动顺序和转调后的游戏行为需要受控运行另行证明。
