# 客户端下行出队：六处观察边界与运行限制

日期：2026-10-21。当前取得一个正常移动、保存退出的 Mac 本地采样窗口；另一次初始运行发生连接中断，原因仍未确定。**采样文件完整性不代表观察行为稳定、双进程、Linux 或多人资格；G0–G5 均未通过。**

本报告承接[历史四处观察实验](2026-10-20-native-transport-probe.md)及 [G0 内部边界](2026-10-20-g0-transport-boundaries.md)。历史 v1 二进制、回执及结论保持原有范围。当前源码采用 trace v2 / JSON schema 2，增加两个客户端纯载荷出队类别；当前读取器明确拒绝旧格式。

## 静态链路与原生契约

研究仍固定上游 `120fe55c02a5633476998a44f8c3c3c809fa48b0`，分析 ELF 的 SHA-256 为 `1aa58c298d3c32dbcf8cca053021ebe26c618cd32fc852e3177192381a770ecc`；main / sdk 运行模块身份与[来源锁定](../../upstream.lock.json)一致。下列地址仅适用于这份产物。

默认服务端发送 `0x84cdd8` 只处理本地编号 0，交给 `0x84178c` 字节流解析器。完整消息经成员回调适配器 `0x84dc30` 调用 `0x83e524`，后者同步复制进客户端两个队列：首字节 `>0xae` 使用对象 `+0x10310`，其余使用 `+0x2f8`。队列内部为 `[u16LE 长度 | payload]`，没有 CID。

解析器入参是原始 `begin/end`，成员回调收到的向量则含 `data/size/capacity`。二者不能交换 ABI；发送范围、解析完成消息、客户端出队和游戏状态应用也不能等同。

| 客户端主虚表槽 | 固定入口 | 返回范围与调用方 |
|---|---|---|
| `+0x00` | `0x8401c0` | 高操作码队列，原主循环在 `0x2c1f40` 调用后检查有效字节，再同步交给 `0x2e3820`。 |
| `+0x08` | `0x840290` | 低操作码队列，原主循环在 `0x2c1f78` 调用后检查有效字节，再同步交给 `0x2e45a0`。 |

两处均使用 `x0=this`、`x1=cursor*`、`x8=24 字节 optional 结果地址`，已知入口和主循环调用不使用栈参数。空结果只初始化 `+16` 有效字节；有效结果写入 `{begin,end}`，排除内部 u16，推进原调用方游标。返回值借用队列存储，观察器必须在原方法返回后、调用方恢复前同步复制。

Ghidra 的伪代码将隐含 x8 显示成额外首参数；实际 ABI 以汇编及调用方为准，不能照抄该 C 原型。两个入口的前 32 字节相同，不能只靠共享前导字节识别方法。当前画像继续核对精确模块身份、对象、完整主/次虚表和所有表项。

`+0x40/+0x48` 是状态判断，`+0x50/+0x58` 是析构路径；它们不能套用 optional 出队契约。模式 2/3 的句柄分支只属于已观察到的实现条件，未建立可用的远程连接 API。

## 当前实现

[`native/transport-probe`](../../native/transport-probe/format.md)保留原有两处发送和两处服务端出队，再克隆替换客户端 `+0/+8`。完整主虚表、负偏移头和次级对象保持既有保护。六个原方法各调用一次，保留整数/向量参数、返回寄存器、NZCV 和原 x8 结果地址；没有新增游戏消息、代码页补丁或异步 Guest 访问。

trace v2 类别 5/6 为 `client_high_postpop` / `client_low_postpop`，只复制纯载荷，不允许连接号标志。服务端类别 3/4 仍保留 CID4，并复用入口解码器核对。短客户端消息不会被裁去四字节。报告包含六类摘要；只有服务端出队生成去 CID 的摘要，客户端摘要覆盖完整载荷。

既有 `OPEN → CLOSING → CLOSED` 屏障覆盖四种出队的原调用和复制。它只结束采样准入，不排空游戏解析器或队列，也不承担未来 IPC 的排空。客户端出队证明调用方拿到了字节；低队列后续仍有状态判断和延后处理，不能据此断言状态应用。

## 验证与下一步

本机 `make check` 通过，核心覆盖率 91.2%，读取器 96.0%；23 项 Python 合成测试、原生六入口 ABI/自有字节/保护页/结束屏障测试及 ASan/UBSan 通过。独立代码与运行差异审查没有找到确定的 critical/major 原生缺陷；发现的主要格式文档不一致已按 v2 整体同步。远程 CI 以本分支实际结果为准。

下一步应先解释或明确复现初始断开，并核对装载、活跃、离开与延后处理的完整状态链，再验证受界限的跨进程字节转运。一个游戏世界加一个宿主中继进程只能证明 IPC，两个离线游戏进程也不能证明共享一个权威世界。真正分离客户端与权威逻辑仍需模式设置、句柄生命周期、线程安全点及客户端停止本地权威运算的证据。Linux、四人角色归属、可靠检查点和手机结果返回继续独立验收。

私人证据位于 `.tmp/experiments/g0-s2c-lifecycle/`、`.tmp/experiments/g0-s2c-qualification/` 及对应所属运行目录；公开资料不包含真实载荷、玩家标识、存档内容、截图或原始伪代码。
