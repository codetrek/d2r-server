# 原生传输观察：限定采样与实际消息对照

日期：2026-10-20。范围：固定 Darwin ARM64 完整客户端、本地单机、显式关闭的采样窗口。**G0–G5 均未通过；Linux、双进程与多人未获资格。**

本文固定提交 `58a8cc0` 的历史 trace v1 / 四处观察语义与回执；当前源码和格式已升级为 v2 / 六处，见[客户端出队报告](2026-10-21-s2c-client-consumption.md)。下列方法数量、示例读取器和摘要均指历史实现，不能用当前读取器解释旧文件。

本报告承接 [Mac 单机基线](2026-10-20-mac-runtime-fixture.md)及 [G0 静态边界](2026-10-20-g0-transport-boundaries.md)。本轮新增原生观察器、观察变体构建入口、Go 读取器和 CLI，并对最终变体完成实际移动及保存退出实验。它记录本地调用，不是网络协议实现；生产控制进程仍返回未就绪 503、引擎不可用和联机不可用。

## 构建与 ABI 边界

[`native/transport-probe`](../../native/transport-probe/format.md)固定模块身份、平台、对象与全部已知虚表项。构建只对原始 `main.c` 编译单元加入 `-Drun_module_inits=d2r_observed_run_module_inits`，不修改上游源文件字节。包装器同步调用真实初始化函数一次，在全部构造器完成后、原 `nnMain` 流程开始前验证画像并安装四个观察方法。原始初始化与各垫片的单一定义由构建符号检查核对。

服务端复制 14 个主虚表方法及两个负偏移头，客户端复制 26 个方法及两个头，仅替换四个槽，客户端次级虚表保持原值。ARM64 垫片保留整数/向量参数、NZCV、返回寄存器及原始 `x8` 间接结果地址，原方法执行一次；固定画像的偏移不是任意程序可调用的接口。

[`d2r-mac-probe-build`](../../tools/mac-fixture/README.md)复核父候选、源码、模块、元数据、资源、着色器和原生只读快照后，生成独立的 `built_unexecuted` 变体。构建工具不执行游戏；父候选的运行记录也不自动适用于新二进制。

## 观察语义与显式结束

发送方法记录是**尝试**，不证明投递；原方法忽略的模式、连接号或状态会在读取跨度之前判断。客户端模式 3 明确产生缺口，不能伪装成忽略。出队记录只在原方法返回后读取已初始化的有效字节；空结果不读取未初始化的描述符或填充。有效出队复制 `[u32LE 连接号 | 载荷]`，没有内部队列的 `u16` 长度前缀。

文件固定 64 MiB、头部 256 字节、记录头 64 字节并对齐到 8 字节，单条观察上限 1 MiB。该上限仅限制采样资源。复制字节归映射所有，提交前缀仅在整条记录完成后发布；文件不保存 Guest 指针或寄存器原值。

运行需要 `D2R_PROBE_MODULES`、新建的 `D2R_TRANSPORT_TRACE` 和初始不存在的 `D2R_PROBE_STOP_PATH`。控制方创建所属停止标记后，观察器按 `OPEN → CLOSING → CLOSED` 停止新采样准入，等待已接纳的原方法及出队复制完成，同步文件并发布关闭标志。控制线程只检查宿主文件和采样状态。区间外调用继续原样转发，不改变采样计数。

实际宿主退出使用 `_exit`，因此不能依赖 `atexit`。未显式结束的文件即使有合法提交前缀，也只是暂定片段。错误、溢出、线程违规或采样缺口均使完整性不合格。`CLOSED` 证明声明窗口结束，不证明整个进程生命周期、所有模式、全部线程或所有流量均被覆盖。

## Go 读取器与报告

`internal/transporttrace.Read(io.ReaderAt, size)`验证固定画像、版本、容量、已提交边界、计数、种类、标志、保留字节、对齐、连续序号及归属线程。只为有效出队调用 `guestingress.DecodeReceiverBuffer` 并核对前缀和连接元数据；没有逐记录无限列表或按文件容量分配内存。

以下示例使用该历史提交构建的 v1 读取器；当前构建只读取 v2。

```sh
./bin/d2r-trace -input .tmp/owned-run/transport.trace
./bin/d2r-trace -input .tmp/owned-run/transport.trace -report .tmp/owned-run/new-report.json
```

报告只给出四类统计、帧范围、逐类复制字节摘要、模块身份及错误/缺口。`-report` 排他创建权限 0600 的新文件。损坏格式、矛盾模式或不合格采样退出 1；不合格但可解析的片段仍输出明确问题。`capture_integrity_eligible` 仅评价声明窗口的文件完整性，`g0_qualified` 和 `game_worker_qualified` 始终为 false。

审查发现客户端模式 1/3 被错误标成 `IGNORED` 时曾可能获得完整性通过；已加入拒绝及回归测试。其他忽略模式保留，真实模式 3 缺口仍可解析并明确不合格。

## 最终变体的实际运行

两次独立场景均使用上表最终变体，保持网络拒绝、原始输入与备份只读、私人写入目录和所属进程管理。没有把原始载荷、玩家名、存档摘要或截图发布到仓库。

| 场景 | 实际观察 |
|---|---|
| 本地空闲世界 | 1,001 条记录；37 条客户端系统输入与 37 条有效系统出队逐条、逐字节及顺序一致；玩法队列只有空结果。 |
| 本地实际移动 | 1,284 条记录、最大 tick 213；690 次发送尝试（602 S2C、88 C2S），594 次出队调用（62 系统有效、26 玩法有效、506 空结果）。 |
| 移动采样完整性 | 画像与安装有效，关闭标志完成，错误、溢出、线程违规均为 0；读取器完整性合格。 |
| 正常保存退出 | 移动后保存退出，退出请求后 3 次实际保存提交，返回菜单，SIGTERM 后退出码 0；测试副本角色变化，原始 24 文件备份保持不变。 |

移动场景的 **62 条系统输入和 26 条玩法输入，分别与各自通道的全部有效出队载荷逐条精确匹配且顺序一致**；比较时仅移除出队的四字节连接前缀，所有连接号均为本地 `0`。没有声称两个通道之间存在同样的全局顺序。

受控 HID 实际给出右向值 32767 后恢复中立。玩家绑定从实际移动诊断解析，同一玩家有 26 个不同坐标样本，另有 25 条实际十六进制操作码 `0x42` 的移动诊断。世界截图存在。此场景耗时 15.455 秒；私人 trace SHA-256 为 `9728a63de4416ee3719efd41ef66b9b21f8067f0a235f14c4ffdf5fae4b7f2f3`。

这些记录证明在观察窗口内，原有单进程本地链路仍能执行系统与玩法消息，并取得上述逐通道对照。观察器没有构造或投递消息，没有连接远程客户端，也没有完成双进程桥接。正常保存提交不证明崩溃、断电或跨玩家一致检查点。

## 检查、来源与下一步

原生合成 ABI、空结果保护、忽略描述符、线程、容量及关闭屏障测试通过，ASAN/UBSAN 通过。`make native-probe-test` 明确要求 Darwin ARM64；CI 增加 `macos-26` ARM 原生测试通道。Python 基线/变体构建工具的 23 项合成测试通过；Go `make check` 核心覆盖率 91.2%，读取器 95.9%、CLI 92.0%。独立审查无未解决 critical/major。本分支远程 CI 需按实际运行核对，配置不代表通过。

私人记录保留在 `.tmp/mac-fixture/probe-public-stop-barrier/`、`.tmp/experiments/g0-boot-qualification/latest-probe-world-run.json`、`latest-probe-movement-run.json`，以及后者关联目录中的 `movement-qualification.json` 和 `transport-report.json`。原生格式及便携构建命令分别由原生目录和工具 README 维护；公开 CI 仅使用合成输入。

下一步是利用这个固定观察基线补齐生命周期及 S2C 消费端证据，进行独立的双进程往返，再验证 Linux 无界面运行、四人归属和一致结果恢复。服务器 CPU 仍待定，G0–G5、生产房间引擎、Linux、多人和双进程资格均保持未通过。
